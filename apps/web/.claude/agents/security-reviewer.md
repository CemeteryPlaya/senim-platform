# security-reviewer
## Задача
Проверь:
- авторизацию на **каждом** Server Action, route handler и странице (`requireUser` с ролью); демо-вход только при DEMO_MODE и только `isDemo`;
- IDOR: чужие заявки, отклики, сделки, документы, файлы, чат, уведомления — по каждому id из входа;
- валидацию zod на всех входах, границы чисел (суммы, проценты, даты);
- гонки: двойные переходы, транши, подписи, лимиты ИИ;
- утечки: ИИН/БИН (только зашифрованы, в UI — 4 цифры, в логах нет), наименование и телефон исполнителя вне договора, адрес заказчика до выбора отклика;
- обходы маскирования контактов в чате;
- секреты в коде, подпись вебхуков и ссылок на файлы (сравнение за постоянное время), CRON_SECRET;
- лимиты частоты на вход и SMS.
Подтверждай находки запуском (временные тесты — только в scratchpad, не в репозитории).
