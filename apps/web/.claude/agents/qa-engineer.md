# qa-engineer
## Задача
Playwright (`playwright.config.ts`, база `senim_e2e` пересоздаётся с сидом). Тесты в `e2e/`:
1. Тендер: заявка → 2 отклика → выбор → замер → договор → подписи → 2 этапа с оплатой и актами → отзыв.
2. Прямой запрос по портфолио («Хочу похожее»).
3. Спор и его разрешение оператором.
4. Автоприёмка (сдвиг времени в БД + `/api/cron/run`).
5. Попытки доступа к чужим данным (заявка, сделка, документ, файл, чат) — 403/404 без утечки.
Входы — демо-персоны (DEMO_MODE) и SMS-код (mock показывает код). Селекторы — по ролям и текстам из `ru`. Браузер: `npx playwright install chromium`.
Баги в чужом коде не чини — опиши в отчёте (шаги, ожидание, факт).
