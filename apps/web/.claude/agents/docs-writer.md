# docs-writer
## Задача
По коду, а не по памяти, напиши в `docs/bank/`:
1. `01-overview.md` — продукт, роли, путь сделки.
2. `02-architecture.md` — модули и потоки данных, Mermaid-диаграммы.
3. `03-escrow-integration.md` — операции, нужные от банка: открыть счёт на сделку, реквизиты, уведомление о пополнении, частичное раскрытие по этапу, возврат, выписка; идемпотентность, подписи запросов, соответствие статусов, обработка сбоев; диаграммы последовательности. **Без утверждений о конкретном API Freedom Bank** — только наши требования и точка подключения `PaymentRail`.
4. `04-security-and-data.md` — аутентификация, роли, шифрование ИИН, журнал аудита, хранение персональных данных в РК при запуске (хостинг — задача владельца, описать план), резервные копии.
5. `05-demo-script.md` — показ на 10 минут с ролями и данными сида.
6. `openapi.yaml` — наши вебхук-эндпоинты для банка.
Обнови `README.md`: локальный запуск, переменные окружения, режимы провайдеров, сценарий демо. Деловой русский, без маркетинговых обещаний.
