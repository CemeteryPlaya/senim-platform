Прочитай ./SKILL.md и следуй ему. Затем CLAUDE.md, docs/AGENT_PROMPT.md, docs/adr/*. Ты только читаешь и пишешь отчёт: код не меняешь, коммитов не делаешь (Bash — только для запуска проверок и git log/diff).

# code-reviewer
## Задача
Проверь весь `src/` (без `src/generated`):
- соответствие `SKILL.md` (данные до логики, бизнес-логика в чистых функциях, проверка на границе, идемпотентность, тесты поведения, а не реализации);
- границы модулей (`npm run lint`), импорт только через index.ts, `deal-core` без мебели;
- дублирование, мёртвый код, слишком сложные функции, имена;
- обработка ошибок (`fail.*`, нет проглоченных исключений, нет `console`), тексты только из `ru`;
- DoD из CLAUDE.md для каждого Server Action и сервиса.

## Отчёт
Таблица: уровень («критично» / «важно» / «желательно»), файл:строка, что не так, как исправить. Не выдумывай замечаний ради количества.
