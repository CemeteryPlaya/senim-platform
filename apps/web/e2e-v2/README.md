# e2e нового интерфейса (`/v2`)

Конфигурация — `playwright.v2.config.ts`; сервер, порт `3110` и стенд (identity, mesh) те же, что у e2e старого интерфейса
(`e2e/web-server.ts`). Сервер и стенд поднимает владелец — сценарии их не запускают и не останавливают.

## Наборы

- **Обычные сценарии (чтение)** — `e2e-v2/*.spec.ts`, проекты `mobile` и `desktop`. Данные не пересеваются: сценарии
  заводят новых людей (свежие номера) или читают засеянные данные. Запуск: `npm run test:e2e:v2`.
- **`flows`** — `e2e-v2/flows/*.spec.ts`, проекты `flows-mobile` и `flows-desktop`. Меняют данные сделок (полный путь сделки,
  спор, торг). Появляются только при `E2E_FLOWS=1`; перед ними проект `reseed` один раз за прогон пересевает базу
  (`reseed.setup.ts`: миграции и сид). Пересев стирает данные базы и сбрасывает сессии и коды всего стенда (`ResetDemo`),
  в том числе вход людей на сервере 3110 — запускайте не чаще одного-двух раз за группу задач.

## Порядок запуска

1. Сначала обычные сценарии (без `E2E_FLOWS`):
   `E2E_DATABASE_URL=postgresql://postgres:postgres@localhost:5442/senim_v2web_e2e npx playwright test -c playwright.v2.config.ts --output <папка вне репозитория>`
2. Потом `flows`:
   `E2E_FLOWS=1 E2E_DATABASE_URL=… npx playwright test -c playwright.v2.config.ts --project flows-mobile --project flows-desktop --output <папка вне репозитория>`
3. После `flows` сценарии чтения, которые зависят от сида (засеянные сделки и заявки), могут падать с текстом «нужен
   пересев»: `flows` изменили данные. Пересейте базу одним запуском `E2E_FLOWS=1 … --project reseed` и снова запустите
   обычные сценарии.

## Состояние входа

Вход засеянными людьми тратит коды (не больше 5 в час и 10 в сутки на номер), поэтому сценарии входят один раз и хранят
состояние входа (`storageState`) в **временной папке ОС**: `%TEMP%/senim-e2e-v2-states` и `%TEMP%/senim-e2e-v2`. После
пересева сессии в них недействительны: **удалите обе папки** перед следующим запуском, иначе сценарии возьмут чужое
состояние.

## База

Только `senim_v2web_*` на `localhost:5442` (для e2e — `senim_v2web_e2e`). `assertSafeDatabase` (`safe-database.ts`) не даёт
пересеять любую другую базу. Базы `senim`, `senim_test`, `senim_e2e` принадлежат старому интерфейсу — их не трогать.
