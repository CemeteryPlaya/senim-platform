# Открытые вопросы

Вопросы, по которым решение принимает владелец проекта. Работа продолжается по текущему решению из `docs/AGENT_PROMPT.md`, раздел 2.

| # | Вопрос | Текущее решение | Кто поднял |
|---|---------|-----------------|-----------|
| 1 | Папки `.agents/` и `.windsurf/` лежат в git (скиллы сторонних инструментов, `.claude/skills` — симлинки на `.agents/skills`). Оставить их в репозитории или вынести? | Не трогаем | Фаза A |
| 2 | `SKILL.md` требует инструменты `crapper`, `dryer`, `mutator`. В окружении их нет. Нужны ли конкретные утилиты (например, Stryker для мутаций, jscpd для дублей)? | Покрытие через vitest, дубли и сложность проверяет `code-reviewer` вручную | Фаза A |
| 3 | Монетизация: в старом MVP была комиссия 6% с исполнителя. В новых решениях она не упоминается, а деньги не проходят через платформу. Как и когда берём плату? | Комиссию в коде и интерфейсе не показываем | Фаза A |
| 4 | Компания (ТОО) может иметь нескольких сотрудников (менеджер, замерщик). Нужны ли несколько пользователей на один профиль исполнителя? | Один пользователь на профиль | Фаза A |
| 5 | Макетов в `docs/design/mockups/` на старте нет. | Токены и компоненты собраны по правилам доступности; при появлении макетов меняются только токены | Фаза A |
