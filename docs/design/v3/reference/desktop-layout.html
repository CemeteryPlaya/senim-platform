Как устроен экран на компьютере?

Главная покупателя в выбранном стиле B. На телефоне в обоих вариантах остаётся нижняя панель из 4–5 вкладок — различается только компьютер. Серые прямоугольники с подписью «фото» — места для настоящих фотографий работ вместо нынешних рисованных картинок.
