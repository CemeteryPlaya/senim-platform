# Чек-лист ревью вида

Ревьюер получает скриншоты (телефон и компьютер, светлая и тёмная темы), этот файл, `rules.md` и эталоны из `reference/`. Код не читает. По каждому скриншоту проходит список и отвечает находками в формате:

`[блокирует | стоит поправить | мелочь] <файл скриншота> — что не так — какое правило — как должно быть`

«Блокирует» — нарушение из разделов 1–3 или нечитаемый текст. В конце — одна строка: «принято» или «нужны правки».

## 1. Характер

- [ ] Экран выглядит спокойным и взрослым: нет цветных кружков, плиток-иконок, рисованных картинок, эмодзи.
- [ ] Нет кнопок-«таблеток», обводок 2 px, шрифта жирнее 600.
- [ ] Зелёный встречается только у статуса, денег под защитой, ссылки-пояснения, прогресса.
- [ ] Карточки без рамок и теней; тень только у плавающих элементов.

## 2. Понятность

- [ ] Один заголовок экрана, и по нему ясно, где находишься.
- [ ] Главная кнопка одна, и она очевидна за секунду.
- [ ] Первая карточка отвечает на «что сейчас и что от меня нужно» (для экранов сделки и заявки).
- [ ] На вложенном экране видна «Назад» с названием родителя.
- [ ] Пустой список объясняет, зачем раздел, и предлагает действие.
- [ ] Нет слов «демо», «тестовый», «комиссия», «эскроу».

## 3. Версия устройства

- [ ] Телефон: панель вкладок внизу, плавающая; главная кнопка в нижней части экрана; содержимое не уходит под панель; нет горизонтальной прокрутки.
- [ ] Компьютер: меню сверху (у оператора — слева); содержимое по центру, не шире ~1100 px; нет нижней панели вкладок.
- [ ] Ни одна версия не выглядит как растянутая или сжатая другая.

## 4. Ритм

- [ ] Отступы по шкале 4 / 8 / 12 / 16 / 24 / 32 / 48; одинаковые блоки имеют одинаковые отступы.
- [ ] Заголовки одного уровня одного размера на всех скриншотах.
- [ ] Выравнивание по одной левой линии; суммы — табличными цифрами, в одну колонку.
- [ ] Текст не обрезан и не наезжает; длинные названия переносятся.

## 5. Темы

- [ ] Тёмная тема: фон чёрный, карточки `#1c1c1e`, главная кнопка светлая; нет «забытых» белых или чёрных пятен.
- [ ] Вторичный текст читается в обеих темах.
- [ ] Полупрозрачные панели читаемы поверх содержимого в обеих темах.

## 6. Цельность (сквозной просмотр в конце этапа)

- [ ] Одинаковые элементы на разных экранах выглядят и расположены одинаково.
- [ ] Экраны разных ролей выглядят как один продукт.
- [ ] Сравнение с эталонами: тот же характер, что в `mobile.html` и в варианте B.
