# Правила дизайна v3

Источник: `docs/superpowers/specs/2026-11-12-frontend-redesign-design.md`, разделы 4–6. Этот файл читают исполнители и ревьюеры перед каждой задачей. При расхождении прав документ-спека.

## Эталоны (`reference/`)

Файлы — фрагменты HTML из обсуждения с владельцем, открываются в браузере как есть.

| Файл | Что выбрано |
| --- | --- |
| `visual-style.html` | вариант **B** «спокойный, как Apple»; A и C отвергнуты |
| `desktop-layout.html` | вариант **A** «меню сверху» для покупателя и мастера; меню слева — только оператор |
| `mobile.html` | принято целиком: вход с выбором роли, главная, сделка со шторкой |
| `hints.html` | приняты 1, 2, 3, 4, 6; вариант 5 (постоянная подсказка под полем) отвергнут |

Эталоны задают характер, а не пиксели: точные значения — ниже и в `src/kit/tokens.css`.

## Цвет

| Можно | Нельзя |
| --- | --- |
| Фон страницы `canvas`, карточки `surface`, плавающее `raised` | Цветные фоны разделов, градиенты, цветные плашки ради украшения |
| Одна главная кнопка `action` (тёмная в светлой теме, светлая в тёмной) | Зелёная кнопка; две главные кнопки на экране |
| `accent` — статус, деньги «под защитой», ссылка-пояснение, прогресс | `accent` как фон кнопки, заголовка, иконки-кружка |
| Только роли-токены | Hex в коде экранов, стандартные палитры Tailwind |

Обе темы обязаны читаться: любой текст ≥ 4,5:1 к своему фону.

## Типографика

| Можно | Нельзя |
| --- | --- |
| Inter; вес 400, 500, 600 | Вес 700 и выше |
| Основной текст 17 px / 1,45 | Основной текст меньше 17 px |

| Заголовок раздела 20 px, −0,02em; заголовок карточки 17 px / 600 | Больше одного `<h1>` на экране |

## Форма и глубина

| Можно | Нельзя |
| --- | --- |
| Карточка: радиус 18 px, без рамки и тени на `canvas` | Рамка 2 px, тень у карточки в потоке |
| Кнопка 48 px, радиус 14 px (телефон) / 12 px (компьютер) | Кнопка-«таблетка», обводка, высота основной кнопки меньше 48 px |
| Поле 48 px, радиус 12 px, линия `line` | Поле без видимой границы |
| Тень только у плавающего: панель вкладок, шторка, поповер, меню, тост | Тени для «объёма» |
| Полупрозрачность у шапки и панели вкладок | Полупрозрачное поверх полупрозрачного |
| Иконки lucide, линейные, 20–24 px, цвет текста | Иконка в цветном кружке или квадрате; иконка-плитка как навигация |
| `PhotoSlot` — ровная заглушка до появления фото | Рисованные картинки, эмодзи, стоковые иллюстрации |

## Отступы

Шкала: 4, 8, 12, 16, 24, 32, 48 px (в `rem`). Внутри карточки 16 px; между карточками 12 px; между разделами 24–32 px; поля экрана 16 px на телефоне. Значения мимо шкалы — только с причиной в комментарии.

## Экран

- Один `<h1>`, одно главное действие (`data-primary-action` не больше одного).
- Первая карточка отвечает на «что сейчас происходит и что от меня нужно».
- Второстепенные действия — `quiet`-кнопки, ссылки или меню.
- «Назад» видна на каждом вложенном экране и называет родителя.
- Телефон: главная кнопка внизу, над панелью вкладок; пояснения и подтверждения — шторкой.
- Компьютер: содержимое по центру, не шире 1100 px; пояснения — поповером, подтверждения — диалогом.
- Версии не смешиваются: никаких брейкпоинтов, превращающих одну в другую.

## Подсказки

| Приём | Где | Компонент |
| --- | --- | --- |
| Список первых шагов | сверху главной, пока не пройден путь до первой сделки или заказа | `FirstSteps` |
| «Что сейчас происходит» | первая карточка сделки и заявки | `NowNext` |
| Пояснение по нажатию | только сложные места: защита сделки, гарантия оплаты, где деньги, спор, проверка мастера, согласие, скрытые контакты | `Explain` |
| Обучающий пустой экран | каждый пустой список | `EmptyState` |
| «Помощь» | под содержимым главной и сделки; раздел `/help` | `HelpBlock` |

Нельзя: обучающие туры, постоянный текст-подсказка под каждым полем, подсказка, повторяющая подпись поля. Ошибка ввода показывается сразу у поля.

## Тексты

Коротко, обычными словами, на «вы». Глагол на кнопке называет результат («Принять мебель», а не «Ок»). Нет слов «комиссия», «эскроу», «демо», «тестовый». Покупатель видит «Защита сделки (2%)», мастер — «Гарантия оплаты и клиента (4%)», деньги — «в банке под защитой». Нигде не сказано, что деньги проходят через счета платформы.

## Движение

- Нажатие отзывается мгновенно (масштаб 0,97 за 100 мс).
- Пружины только у шторки, поповера, диалога, смены шага; по умолчанию без отскока.
- Шторка тянется за пальцем, прерывается в любой момент, закрывается броском.
- Вход и выход — по одному пути; поповер растёт из своей кнопки.
- Только `transform` и `opacity`.
- `prefers-reduced-motion` — проявление; `prefers-reduced-transparency` — сплошной фон.
- Нельзя: анимация ради украшения, появление содержимого страницы «с подъездом», параллакс, бесконечные циклы.
