# Демо-данные (сид, ТЗ MVP v1.0)

`npm run db:reset` или `DEMO_MODE=true npm run db:seed`. Код — `src/demo/`: описание — `data.ts`, «до сделок» — `seed.ts`, сделки — `deals.ts`. `resetDemo(db)` используется для «Сбросить демо» (TRUNCATE всех таблиц, в том числе `Session`: после сброса все выходят). Телефоны — +7 700 000 XX XX, ИИН/БИН — тестовые с верной контрольной суммой, IBAN выплат — `KZ..000DEMO…` (верный mod-97, банка с кодом 000 нет).

Сид — в два шага:
1. **До сделок** (одна транзакция, даты «N дней назад»): справочник и демо-цены материалов, люди, мастера (портфолио, KYC с тестовыми PDF «ТЕСТОВЫЙ ДОКУМЕНТ»), заявки, отклики и торг (раунды `PriceProposal`), сценарии до договора, уведомления регистрации и откликов.
2. **Сделки** — настоящими сервисами, от имени тех, кто нажимает кнопку: `requests.acceptPrice` → `deal-core.createDeal` (оферта — PDF documents), подписи documents (собственноручно — напечатанное имя, ЭЦП — mock), `payForDeal`, `startWork`, `addProgressReport`, `submitReady` (фото JPEG через files, GPS у адреса или в ~2 км), подпись акта, `cancelDeal`, `openDispute`/`resolveDispute`; на manual — оператор подтверждает операции номером `ТЕСТ-NNNN`, датой и тестовым сканом (PDF «ТЕСТОВЫЙ ДОКУМЕНТ — не настоящий»). Даты этих событий — момент сида. Все сделки `isDemo`, все операции журнала `isTest`, суммы — `computeDealMoney`, журнал — единственный источник денег. Порты (`src/ports.ts`) сид регистрирует сам.

## Заявки без сделки

- №18 OPEN, тендер Айгерим на кухню, 3 отклика: Исп. №3 — встречная цена покупателя 980 000 ₸ ждёт мастера; Исп. №2 — цена отклика ждёт покупателя; Исп. №4 — третий раунд (1 020 000 → 940 000 → 990 000) ждёт покупателя. Чат с маскированным контактом.
- №19 OPEN, прямая заявка Данияра «Хочу похожее» на работу Исп. №7, без откликов · №20 DRAFT (шаг 2) · №13 CANCELLED с отклонённым откликом.
- У всех заявок пути ТЗ `preContractFlow: null`; у каждого живого отклика — одна открытая цена (или принятая, если есть сделка).
- Сценарии до договора (флаг `preContractFlows`, ADR-005), сеются последними (№22–28): сценарий 1 — OFFER_CHOSEN (№22), MEASURING (№23), OPEN после «замер без сделки» (№24, плата за выезд 10 000 ₸); сценарий 2 — PLATFORM_MEASURING, назначен замерщик (№25); сценарий 3 — OFFER_CHOSEN (№26); сценарий 4 — OFFER_CHOSEN, ждёт залога (№27); сценарий 5 — OPEN с размерами заказчика (№28). При выключенном флаге экраны их читают, новых шагов не предлагают.

## Прочее

- «Вдохновение» и портфолио: 20 работ портфолио, 6 — в «Подборке Сенім» (флаг `inspiration` выключен — раздела нет в меню). Портфолио из сделок (флаг `dealPortfolio`) в сиде нет.
- Ссылки в уведомлениях сида: `/requests/:id`, `/executor/requests/:id`, `/operator/executors/:id`; уведомления сделок и денег (`deal.offer.ready`, `deal.signed`, `deal.ready`, `money.*`, `dispute.*`) пишут сервисы.
- Сид и `npm run jobs` запускаются через `tsx --import ./scripts/server-only-hook.mjs` (пакет `server-only` подменяется пустым модулем, как в тестах). Файлы (фото, PDF, сканы) — в хранилище `STORAGE_PROVIDER` (по умолчанию `./storage`).
- Тесты сида: `src/demo/seed.int.test.ts` (сделки во всех статусах, журнал сходится с формулами, manual, споры, GPS, KYC), `requests/seed-compat.int.test.ts`, `identity/demo.int.test.ts`, `operator/demo.int.test.ts`. Хранилище в тестах — временная папка (`useSeedStorage`).
