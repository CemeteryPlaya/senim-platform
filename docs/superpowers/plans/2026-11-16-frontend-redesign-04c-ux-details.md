# Новый интерфейс, мелочи удобства — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** поля ввода и поведение v2 удобны как в известных продуктах (Kaspi, Apple, Stripe, Airbnb, Telegram): маски и правильные клавиатуры, автозаполнение кода, ошибки у полей с фокусом, отклик на каждое касание, устойчивость к обрыву сети, копирование и связь в одно касание — без изменения продуктовых инвариантов.

**Architecture:** общие решения — в `src/kit` (поля с маской, кнопки копирования, контакты, ссылка на карту, скелетоны, плашка «Нет связи») и `src/app/(app)/_shell` (`useActionForm`, навигация «Назад», оболочка); экраны только подключают их. Поведение и данные модулей не меняются.

**Tech Stack:** Next.js 16.4.3 (`loading.tsx`, `useLinkStatus` — сверять по `node_modules/next/dist/docs/`), React 19, Tailwind 4, `@/kit`, vitest, Playwright.

**Spec:** аудиты `docs/design/v3/ux-audit-2026-11-16-forms.md` (47 находок, общие решения kit, топ-15) и `docs/design/v3/ux-audit-2026-11-16-behavior.md` (37 находок, топ-15) — значения и места; спека `docs/superpowers/specs/2026-11-12-frontend-redesign-design.md` (разделы 4–6, 18) и `docs/design/v3/rules.md`.

## Global Constraints

- Пути — от `apps/web/`. Ветка `frontend-v2`, без worktree, без пуша; коммит только своих файлов по явным путям.
- v1 и модули `src/modules/*` не трогать (если без модуля нельзя — минимально, с обоснованием; API внешних сервисов не выдумывать: формат ссылок 2ГИС, Яндекс Карт, WhatsApp — только по их документации, иначе не делать).
- Инварианты `CLAUDE.md`: контакты и адрес только после оферты (как отдаёт модуль); ИИН/БИН/IBAN после сохранения — 4 последних символа; деньги — тиыны, маска только на вводе/показе, на сервер — целые тиыны через существующие схемы; тексты только из `ru`; постоянных подсказок под полями нет (пример внутри поля или по нажатию).
- Доступность: метка у поля всегда видна (placeholder не заменяет метку), маска не ломает диктор и вставку, ошибки — `aria-invalid`/`aria-describedby`, ≥ 48 px, крупный шрифт, reduced-motion; шрифт полей ≥ 16 px (iOS не масштабирует).
- Сторожа kit/features, две версии по устройству (`desktop:`/`mobile:`), один `h1`, одно главное действие.
- Проверки в задаче — точечные; снимки телефона — с user-agent iPhone; полный check, пересев, e2e — автор. Не больше четырёх агентов.

## Review Focus

1. Вставка и автозаполнение: телефон с 8/+7/скобками/пробелами, код из SMS целиком, сумма «1 200 000» и «1,2 млн», IBAN строчными — дают верное значение; диктор читает поле.
2. Обрыв сети на каждом действии (подпись, подтверждения, отправка форм) — человек видит ошибку и может повторить, введённое не теряется.
3. Мгновенный отклик: касание вкладки или ссылки меняет вид сразу; скелетон не «мигает» на быстрой сети.
4. Контакты и карта — только после оферты; копирование не раскрывает лишнего.
5. «Назад» сохраняет прокрутку и фильтры и не ломает глубокие ссылки (пришёл из уведомления — «Назад» ведёт к родителю).

### Task U1: поля с маской и формы в kit (Opus 5.5)

Аудит форм: общие решения kit и топ-15 (п. 1, 2, 5, 7, 8, 10, 13–15). `PhoneField` (постоянная приставка «+7», маска, нормализация вставки, `autocomplete="tel"`, `inputMode="tel"`), `CodeField` (`one-time-code`, вставка целиком, автоотправка после последней цифры, фокус при открытии шага), `MoneyField` (пробелы тысяч при вводе, «₸» внутри, разбор «1,2 млн»/«1.2 млн»/«1 200 000», `inputMode="numeric"`, значение — тиыны), `IinField` (группы, контрольная цифра до отправки — существующая функция), `IbanField` (верхний регистр, группы по 4, проверка существующей схемой; название банка — только если есть надёжный источник в коде, иначе без него), `EmailField` (подсказка при опечатке домена — список популярных доменов, выбор по нажатию), поле Instagram (ссылка или ник, «@» заранее, без автоисправления); `useActionForm`: снимать ошибку поля при правке, фокус и прокрутка к первой ошибке. Тесты: маска и вставка (табличные), автоотправка кода, разбор сумм, контрольная цифра, ошибки.

### Task U2: подключить поля и мелочи форм на экранах (Sonnet 5.5)

После U1. ### Task U3: отклик и устойчивость к сети (Opus 5.5)

Аудит поведения: критичные и топ-15 (п. 1–4, 7, 8, 15). Ошибки сети в подписи (`SignArea`: от руки и ЭЦП — подпись не теряется, повтор); `ConfirmDialog` показывает отказ и сеть; `loading.tsx` со скелетонами для основных экранов (без мигания на быстрой сети); мгновенная подсветка вкладки и ссылок (`useLinkStatus`); обновление данных при возврате в приложение; плашка «Нет связи» и повтор; страница офлайн в стиле v2 с тёмной темой.

### Task U4: копирование, контакты, карта, чат, навигация (Sonnet 5.5)

Аудит поведения: топ-15 (п. 5, 6, 9–14) и общие решения: `CopyButton` (тост «Скопировано»), `ContactActions` после оферты (позвонить, WhatsApp — формат по документации, копировать), `MapLink` вместо координат (Яндекс Карты / Google Maps / 2ГИС — только по документации), копирование суммы и назначения платежа при ручном переводе, разделители дней в чате и время у сообщений, без панели вкладок в переписке и при открытой клавиатуре, push-уведомления ведут в v2 и отмечаются прочитанными, «Выйти на всех устройствах» в профиле, «‹ Назад» возвращает с прокруткой и фильтрами (при прямом входе — к родителю), манифест PWA стартует в v2 с цветами v2.
