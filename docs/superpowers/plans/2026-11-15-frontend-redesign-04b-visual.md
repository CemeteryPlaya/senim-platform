# Новый интерфейс, пересмотр вида «тепло, фото, Liquid Glass» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v2 выглядит как продукт крупной компании в стиле Apple: тёплая палитра, крупная типографика, настоящие (пока временные) фото мебели, Liquid Glass в слое навигации и поверх фото, новый лендинг гостя — без изменения поведения, текстов по смыслу и продуктовых инвариантов.

**Architecture:** почти всё — на уровне `src/kit` (токены, утилиты стекла, компоненты) и нескольких экранов-витрин (лендинг, каталог, профиль мастера, главные, портфолио, ход работ). Фото для стенда — временный набор свободных фото (лицензия Unsplash) с одним манифестом; сид стенда и лендинг берут их оттуда.

**Tech Stack:** Next.js 16.4.3, React 19, Tailwind 4, `@/kit`, `next/image`, `next/font` (Inter с осью `opsz`), Motion (если уже в зависимостях; новая зависимость — только с обоснованием в отчёте), vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-frontend-redesign-design.md`, раздел 18 (решения владельца 15.11.2026) — главный; направление и значения — `docs/design/v3/review-2026-11-15-critique.md` (разделы 3.2–3.9: палитра, шкала текста, рецепты стекла, фото, компоненты, движение, лендинг, раскладки компьютера). При расхождении с `rules.md` — прав раздел 18 и разбор.

## Global Constraints

- Пути — от `apps/web/`. Ветка `frontend-v2`, без worktree, без `git stash`, без пуша; коммит только своих файлов по явным путям.
- v1 (`src/app/(legacy)`, `src/ui`) не трогать. Модули `src/modules/*` не трогать (кроме сида стенда, если фото кладутся сидом — задача V3).
- Тексты интерфейса по смыслу не меняются; новые подписи (например «Работа мастера · Астана», подпись временного фото) — только в `ru.app.*`. Продуктовые инварианты `CLAUDE.md` — без изменений (слова денег, контакты, 2%/4%).
- Доступность не ухудшается: основной текст ≥ 17 px; любой текст ≥ 4,5:1 к своему фону — в том числе на стекле и на фото (с затемнением; проверять по самому светлому участку фото под текстом); кнопки и поля ≥ 48 px на телефоне; одно главное действие; «Назад»; клавиатура; увеличенный шрифт; `prefers-reduced-transparency`, `prefers-contrast: more`, `prefers-reduced-motion`; светлая и тёмная темы.
- Стекло — только там, где перечислено в разделе 18 спеки и 3.4 разбора; никогда стекло на стекле; без SVG-преломления.
- Две версии по устройству (`desktop:` / `mobile:`); варианты по ширине окна запрещены сторожем — сторожа `src/kit/guards.test.ts`, `src/features/guards.test.ts` зелёные; новые произвольные значения — именованными токенами.
- Временные фото: только с лицензией Unsplash (свободное использование), без людей в кадре, без водяных знаков; каждое записано в манифест (источник, автор, ссылка, «временное — заменить работой партнёра»). Вес: WebP/AVIF, ≤ 250 КБ на файл, суммарно ≤ 8 МБ в репозитории.
- Без `any`, без `console.log`. Хуки запрещают пути с подстрокой «точка + env» и чтение `.pem`/`.key`. Базы — только `senim_v2web_test` и `senim_v2web_e2e` на 5442.
- Проверки внутри задачи — точечные (`tsc`, `eslint`, `vitest` затронутого); снимки: телефон 390×844 с user-agent iPhone (иначе сервер отдаёт версию для компьютера) и компьютер 1440×900, светлая и тёмная темы — в `shots-<ID>/` рабочей папки; исполнитель открывает свои снимки сам. Полный check, пересев и e2e — автор. Не больше четырёх агентов одновременно.

## Review Focus

1. Контраст на стекле и на фото: самый светлый участок фото под белым текстом; стекло над белой и над тёмной страницей; обе темы; режимы reduced-transparency и high-contrast.
2. Регресс поведения: ни один экран не потерял действие, «Назад», главное действие; e2e чтения и flows зелёные без правки ожиданий по смыслу (правка локаторов допустима).
3. Телефон: док без плиты не перекрывает содержимое и не прыгает при клавиатуре; панель вкладок-стекло читается над фото и над длинным списком.
4. Производительность: `backdrop-filter` только на плавающих элементах (не на сотнях карточек), фото через `next/image` с `sizes`, без сдвига раскладки.
5. Узкое окно компьютера: горизонтальная прокрутка вместо сжатия по слову в строке.
