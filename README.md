# Сенім — демо платформы безопасных сделок

Кликабельный MVP для встречи: заказчик и мебельщик заключают сделку с ЭЦП, деньги замораживаются на эскроу, мастер отчитывается по этапам с фото, выплаты идут траншами, оператор разрешает споры.

**Реальное:** статусная машина сделки, журнал событий и проводок, расчёт траншей и комиссии 6%, чат, фото-отчёты, PWA.
**Имитация:** подпись ЭЦП (NCALayer / eGov QR), банк-эскроу, вход по SMS. Всё это вынесено за интерфейсы в `src/lib/providers/`, и боевые интеграции подключаются заменой модуля.

## Стек

Next.js 16 (App Router, Server Actions) · TypeScript · Tailwind CSS 4 · Prisma 7 + PostgreSQL · деплой на Vercel.

## Локальный запуск

```bash
docker run -d --name safedeal-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=safedeal -p 5440:5432 postgres:17-alpine
# в .env: DATABASE_URL="postgresql://postgres:postgres@localhost:5440/safedeal?schema=public"
npm install
npx prisma migrate deploy
npm run db:seed
npm run dev
```

## Деплой на Vercel

```bash
vercel login
vercel link
vercel integration add neon      # Postgres из Marketplace, DATABASE_URL подставится сам
vercel env pull .env.local
npx prisma migrate deploy && npm run db:seed   # с переменными из .env.local
vercel --prod
```

`npm run build` сам выполняет `prisma generate` и `prisma migrate deploy`.

## Сценарий показа (7–10 минут)

1. **Лендинг** → «Как работает безопасная сделка», комиссия 6%.
2. **Демо-вход за Айгерим (заказчик)** → «Мастера» → Ерлан → «Предложить безопасную сделку». Покажите калькулятор аванса и комиссии.
3. **«Смотреть как: Исполнитель»** (переключатель на странице сделки) → «Предложить изменения»: сумма +50 000 и комментарий. В ленте появляется сообщение.
4. **Заказчик** → «Принять условия» → «Подписать ЭЦП» → eGov Mobile (QR).
5. **Исполнитель** → «Подписать ЭЦП» → NCALayer. Открывается эскроу-счёт.
6. **Заказчик** → «Пополнить эскроу». Деньги заморожены.
7. **Исполнитель** сдаёт этапы с фото (можно сфотографировать что-нибудь с телефона), **заказчик** подтверждает. После этапа «Закупка материалов» мастеру уходит аванс.
8. **Финальная приёмка** → автоматическая выплата, эскроу закрыт.
9. **Оператор** → панель: оборот, доход 6%, спор по «Детской комнате» → «Разделить 50/50».
10. Перед следующим показом: **Оператор → «Сбросить демо»**.

Для показа «вживую» откройте заказчика на ноутбуке, а мастера на телефоне (или в другом браузере): лента и статусы обновляются у обоих автоматически.

Если времени мало, войдите за Айгерим и откройте готовую сделку «Кухонный гарнитур 3,2 м»: там мастер уже сдал этап «Закупка материалов».
